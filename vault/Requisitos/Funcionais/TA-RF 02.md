# Resolução do Sudoku Tradicional

O sistema deve resolver o tabuleiro gerado por um dos métodos: **Probabilidade com 1 tentativa**, **Probabilidade com N tentativas** (limite configurável) ou **Backtracking**, informando se o tabuleiro foi resolvido e quantos quadrantes estão corretos.
