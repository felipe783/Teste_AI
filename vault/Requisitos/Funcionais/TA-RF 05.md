# Treino DQN Local

O sistema deve treinar um agente DQN jogando Snake em janela, salvando checkpoints periódicos (com otimizador, partidas, recorde e epsilon), retomando o treino do último checkpoint e gravando vídeos das partidas próximas do recorde.
